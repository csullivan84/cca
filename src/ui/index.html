    What these results mean

    These results assess colour contrast, not complete WCAG conformance. Large text is at least 18 pt (24 CSS px), or 14 pt (18.67 CSS px) when bold. Text exceptions include logos, incidental text and inactive controls. Non-text results apply to required identifying visuals, not every pixel.

          Preferences & shortcuts

          Shortcuts work while CCA has focus. Use Alt plus a letter, or an available function key. Windows F11/F12 picker keys can be reassigned here.

          Original translations are retained for existing labels; new workbench text currently falls back to English.

          Keyboard shortcuts

          Tokens: %f%, %b%, %ratio%, %aa%, %aaa%. Ratio is unrounded.
